# Agentic privacy, mapped

A field map of *Open and Emergent Problems in Agentic Privacy and Security: A Contextual Angle*
(Bagdasarian, Tsai et al., 2026), the report of the Google Contextual Agent Privacy and Security
(CAPS) Workshop, New York City, November 2025.

- Source PDF: https://storage.googleapis.com/gweb-research2023-media/pubtools/1047874.pdf
- Publication page: https://research.google/pubs/open-and-emergent-problems-in-agentic-privacy-and-security-a-contextual-angle/

**Live: https://idvorkin-ai-tools.github.io/agentic-privacy-field-map/**

Seventeen pages plus a spine:

- **The lens** (`concepts/`): Contextual Integrity applied to agents; the three challenge
  dimensions and the four threat models.
- **The open problems** (`problems/`): one page per problem area, §5 through §12, covering all 51
  numbered open problems. Each problem has an anchor, e.g. `problems/model-reasoning.html#op-8-3`.
- **Guides** (`guide/`): read it in 10 minutes, for builders, glossary.

Original explanation, grounded in the report. Section, page and open-problem numbers are the
report's own; the report is © its authors. Related: [CIMemories, mapped](https://idvorkin-ai-tools.github.io/cimemories-field-map/).
